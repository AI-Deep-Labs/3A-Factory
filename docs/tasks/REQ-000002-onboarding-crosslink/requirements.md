# Requirements

## 1. Yêu cầu nghiệp vụ
- Khi quá trình onboarding một dự án mới được thực hiện, file `docs/project_overview.md` được tạo ra cần chứa hướng dẫn hoặc đường dẫn tới nơi lưu trữ các đặc tả chức năng (Spec Packages). Điều này giúp Developer và Agent mới dễ dàng tìm thấy tài liệu.

## 2. Yêu cầu kỹ thuật
- Chỉnh sửa file `.agents/skills/onboarding/SKILL.md`.
- Tại phần "Phase D — Knowledge base `docs/project_overview.md`", bổ sung hạng mục "13. Knowledge Base & Feature Specs" vào danh sách cấu trúc nội dung tối thiểu của file.
- Mô tả của hạng mục này cần chỉ ra việc cung cấp thông tin/đường dẫn đến nơi chứa Spec Packages dựa trên `spec_config.json` nếu có, hoặc ở vị trí mặc định của repo (thường là `docs/tasks/`).

## 3. Ràng buộc
- Không làm thay đổi logic hoạt động hay cấu trúc hiện tại của file `SKILL.md` cũng như các Phase khác.
