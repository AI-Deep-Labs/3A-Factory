# Release Notes — 3.1.0-rc.2

**Status:** Pre-release candidate (Phase 2 — workflow UX + flat skills/commands).  
**Base:** [3.1.0-rc.1](./3.1.0-rc.1.md) → [3.0.0](./3.0.0.md) GA.

## Tóm tắt

3A-Factory **3.1.0-rc.2** cải thiện **trải nghiệm vận hành workflow** (auto-intake, approval tự nhiên, PM mode bắt buộc khi slash) đồng thời **tái cấu trúc nguồn authoring** (skills/commands phẳng, installer copy-only) và **dọn dẹp repo** (xóa layout legacy, guards build/validation).

---

## 1. Auto-intake — `project-manager` bằng ngôn ngữ tự nhiên

Trong repo **đã onboard** (`AGENTS.md`, `.agents/contracts/spec-package.md`, `docs/`), user **không cần** gõ slash command để bắt đầu intake.

| Trước | Sau (rc.2) |
|---|---|
| Phải nhớ và gõ `/triage`, `/project-manager`, … | Mô tả yêu cầu bằng ngôn ngữ tự nhiên |
| Agent có thể bỏ qua PM routing | Agent đọc và thực thi `.agents/skills/project-manager/SKILL.md` |
| Routing không nhất quán | PM route theo `manifest.status` (triage → spec → develop → …) |

**Contract:** `AGENTS.md` § Auto-intake · `templates/skills/project-manager/SKILL.md` § Auto-intake entry · `templates/commands/ai-workflow.md`.

**Ví dụ:** *"Thêm export Excel cho báo cáo doanh thu"* → PM phát hiện repo onboarded → route `triage` / skill con tương ứng theo trạng thái package.

Slash commands (`/triage`, `/develop`, …) vẫn là **override thủ công** khi cần.

## 2. Approval gates — xác nhận tự nhiên thay vì gõ token

User **không bắt buộc** gõ `APPROVED_SPEC_PACKAGE`, `APPROVED_DEVELOP`, `APPROVED_USER_REVIEW`, `APPROVED_DEPLOY`.

| Gate | Hành vi mới |
|---|---|
| Spec package | Agent hỏi **một câu xác nhận** sau spec-review PASSED |
| Develop (high-risk) | Agent hỏi xác nhận trước khi code |
| User review | Agent hỏi nghiệm thu sau converge |
| Deploy | Agent hỏi trước mọi deploy |

**Chấp nhận:** có/không, yes/no, đồng ý/từ chối, hoặc câu tự nhiên tương đương. Token `APPROVED_*` vẫn hợp lệ cho power users.

**Contract:** `.agents/contracts/spec-package.md` § **5.4.1** · template `APPROVAL-CONFIRMATION-template.md` · cập nhật skills: `spec`, `spec-review`, `develop`, `converge`, `deploy`, `project-manager`.

Chi tiết: [docs/approvals.md](../docs/approvals.md).

## 3. `/project-manager` — ép chạy workflow khi slash

Khi user gõ **`/project-manager`**, agent **bắt buộc** vào **MANDATORY PM MODE** — không được skip phase, không tự implement/plan ngoài child skills.

**Ràng buộc (tóm tắt):**

1. Đọc `.agents/rules/agent-mode.md`, rồi `AGENTS.md`.
2. Thực thi **đầy đủ** `.agents/skills/project-manager/SKILL.md` (§ Slash invocation (mandatory)).
3. Session orchestration: **PM → child skill SKILL.md → PM**; route chỉ qua manifest state.
4. Không viết artifact ngoài `docs/tasks/REQ-*` và canonical child skills.

**Nguồn preamble:** `templates/commands/project-manager.md` (`cursorPreamble` + prompt) → installer emit sang Cursor / Claude / Gemini.

Khác với auto-intake: slash **`/project-manager`** là **ép** PM mode cho session; auto-intake kích hoạt PM khi user mô tả yêu cầu tự nhiên (không cần prefix slash).

- Module: `scripts/install/command-adapters.js` (copied to `dist/install/` on build).

**Build:** bundle **70 files** (rc.1: 48).
