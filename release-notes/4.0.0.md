# Release Notes: 4.0.0 (Enterprise Sub-Agent Orchestration)

**Release Date:** 2026-08-04

3A-Factory version 4.0.0 marks a massive architectural paradigm shift from **Monolithic Execution** to **Delegated Sub-Agent Orchestration**. This release brings the framework to Enterprise Grade by enforcing strict role separation and context isolation.

## Major Changes

### 1. DevCrew Sub-Agents (Zero Bias)
We have introduced 6 specialized Personas that act as System Prompts for sub-agents:
- `business-analyst`
- `architect`
- `developer`
- `reviewer`
- `qa-engineer`
- `release-manager`

By isolating the Context Window for each phase, we enforce the **Four-Eyes Principle**. For example, the `developer` sub-agent is strictly isolated from the `reviewer` sub-agent, preventing confirmation bias and ensuring rigorous code quality checks.

### 2. Pure Supervisor (`project-manager`)
The `project-manager` skill has been refactored into a pure Supervisor. It no longer executes task logic itself. Instead, it reads the `manifest.yaml`, spawns the appropriate sub-agent using IDE native tools (e.g., `invoke_subagent`), and waits for a pass/fail report.

### 3. Strict State Mutator Rules
Child skills (`develop`, `qa`, `review`) are now strictly forbidden from mutating `manifest.yaml`. They simply return a status report. The `project-manager` is the sole agent authorized to write state transitions, significantly reducing YAML parsing and indentation errors caused by LLM hallucinations.

## Upgrade Instructions

To install the new V4 architecture into your project, run:
```bash
npx 3a-factory@4.0.0 --agent=all --force
```
This will scaffold the new `.agents/agents/` (Personas) and `.agents/configs/` (Registry) directories into your project alongside the updated skills.
