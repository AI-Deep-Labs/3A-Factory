# Release Notes — 3.1.0-rc.3

**Status:** Pre-release candidate.  
**Base:** [3.1.0-rc.2](./3.1.0-rc.2.md).

## Tóm tắt

3A-Factory **3.1.0-rc.3** sửa lỗi skill onboarding tạo context file cho **tất cả** agent thay vì chỉ agent đang chạy.

---

## Sửa lỗi

### Onboarding: chỉ tạo context file cho agent hiện tại

**Trước (rc.2):** Khi chạy `/onboarding` trên bất kỳ agent nào (Claude, Gemini, Cursor), skill luôn tạo/cập nhật cả `CLAUDE.md`, `GEMINI.md` — dù user chỉ cài 1 agent.

**Sau (rc.3):**

| Agent chạy | File được tạo/cập nhật |
|---|---|
| Claude | `AGENTS.md` + `CLAUDE.md` |
| Gemini | `AGENTS.md` + `GEMINI.md` |
| Cursor | `AGENTS.md` + `.cursor/rules/` (không tạo CLAUDE.md / GEMINI.md) |

**Thay đổi cụ thể trong `.agents/skills/onboarding/SKILL.md`:**

- Thêm section **§ Agent detection** — bảng xác định agent hiện tại theo marker (`.claude/`, `.gemini/`, `.cursor/`) hoặc user stated.
- Phase C: mỗi agent-specific block có dòng **"Do not create if agent is ..."**.
- Output checklist: "Agent-specific context file created/updated **only for current agent**".
- `AGENTS.md` vẫn luôn được cập nhật (shared — all agents read).

---

## Installation

```bash
npx 3a-factory@3.1.0-rc.3 --agent=<your-agent> --force
```
