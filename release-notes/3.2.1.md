# Release Notes — 3.2.1

**Status:** Patch release (GA line).  
**Date:** 2026-07-30  
**Base:** [3.2.0](./3.2.0.md)

## Tóm tắt

3A-Factory **3.2.1** tinh chỉnh **auto-intake / project-manager trigger** và **phạm vi `agent-mode`**, để ngôn ngữ tự nhiên không còn bị ép vào Spec Package khi người dùng chỉ hỏi hoặc giải thích code. Quy trình Spec Package (routing table, gates, child skills) **không đổi**.

---

## Vì sao có bản này

Ở 3.2.0, auto-intake đã cho phép mô tả yêu cầu bằng NL → `project-manager`. Trong thực tế:

1. Hub / `agent-mode` áp “Canonical Workflow ONLY” **không điều kiện** → Q&A dễ bị kéo vào `docs/tasks/REQ-*`.
2. Điều kiện “không gọi PM” nằm chủ yếu ở `AGENTS.md`, trong khi skill PM dùng `disable-model-invocation: true` và `description` chỉ mô tả state-machine → model khó phân biệt lifecycle vs Q&A.
3. Khi user đã gọi slash bước (`/develop`, `/qa`, …) vẫn có thể chồng orchestration PM.

---

## Điểm chính

### 1. Intent gate trước khi mở PM

| Gọi PM khi | Không gọi PM khi |
|---|---|
| Feature / bug / change / enhancement | Pure Q&A, giải thích code, review ad-hoc không gắn REQ |
| Tiếp tục REQ / path `docs/tasks/…` | Meta tooling (trừ khi muốn chạy pipeline) |
| Trả lời approval tại gate đang mở | Đã gọi slash bước (`/triage`, `/develop`, `/qa`, `/deploy`, …) |
| | Bypass workflow |
| | Ambiguous → hỏi 1 câu (mở Spec Package hay chỉ trả lời) |

Nguồn đầy đủ: `.agents/skills/project-manager/SKILL.md` § **Auto-intake entry** → **Intent gate**.  
Hub tóm tắt: `AGENTS.md` § Auto-intake.

### 2. `project-manager` cho phép model-invocation

- Bỏ `disable-model-invocation: true` trên skill PM (các skill bước vẫn tắt).
- `description` kiểu nowx: **AUTO-ACTIVATE** / **DO NOT activate** + ví dụ câu kích hoạt.
- `/project-manager` vẫn **mandatory PM mode** (bind session) — tách rõ với auto-intake (không bind session).

### 3. `agent-mode` có phạm vi áp dụng

`.agents/rules/agent-mode.md` thêm:

- **When these rules apply** — lifecycle / continue-REQ / approval / `/project-manager` / đang trong PM
- **When these rules do NOT apply** — Q&A, explain code, meta, bypass, slash bước khác

Ràng buộc Spec Package (mục 4–5) chỉ còn khi đang trong workflow, không còn đè mọi turn.

### 4. Hub / docs đồng bộ

Cập nhật blurb Intent gate trên: `AGENTS.md`, `CLAUDE.md`, `GEMINI.md`, `.agents/commands/ai-workflow.md`, `.agents/WORKFLOW.md`, `docs/commands.md`, `docs/workflow.md`, onboarding “Next”, README Quick Start.

### 5. Cleanup thư viện

- Xóa template orphan không nằm trong installer list và đã bị thay thế: `REVIEW-template.md`, `QA-REPORT-template.md`, `UT-REPORT-template.md`.
- Sửa path cũ `templates/.agents/…` → `.agents/…` trong contract, WORKFLOW, triage, document templates.
- Gỡ báo cáo one-off `docs/reports/` (review 3.0.0) khỏi tree sản phẩm.
- Validation / tests assert Intent gate, scoped agent-mode, PM model-invocation.

## Không đổi (không breaking)

- Canonical workflow / Spec Package contract semantics
- Approval gates (§ 5.4.1)
- Installer consumer paths (`.agents/skills`, `.claude/commands`, `.gemini/commands`, `.cursor/rules`)
- Hard gates develop / review / QA / deploy

## Installation / Upgrade

```bash
npx 3a-factory@3.2.1 --agent=<your-agent> --force
```

Ví dụ:

```bash
npx 3a-factory@3.2.1 --agent=cursor --force
npx 3a-factory@3.2.1 --agent=claude --force
npx 3a-factory@3.2.1 --agent=gemini --force
npx 3a-factory@3.2.1 --agent=all --force
```

Sau upgrade: mở chat Agent mới nếu danh sách `/` hoặc always-rules còn cache bản cũ.

## Kiểm chứng đề xuất

1. “Giải thích hàm X” → trả lời, không tạo/mở REQ.
2. “Cần thêm tính năng Z…” → auto PM → triage (hoặc continue).
3. `/develop …` → chỉ develop, không chồng PM.
4. `/project-manager` → mandatory PM mode.
5. Câu mơ hồ (“auth nên thiết kế thế nào?”) → soft-confirm một câu.
6. Deploy vẫn chỉ `/deploy` + confirmation.
