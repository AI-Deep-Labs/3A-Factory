# Release Notes — 3.1.0-rc.1

**Status:** Pre-release candidate (Phase 1 — Core Rules Hub + Agent Pointers).  
**Base:** [3.0.0](./3.0.0.md) GA.

## Tóm tắt

3A-Factory **3.1.0-rc.1** giới thiệu kiến trúc **Core Rules Hub + Agent Pointers**: gom các ràng buộc ức chế agent (chống Planning Mode ngầm, cấm artifact ẩn, ép workflow `docs/tasks/REQ-*`) vào một file dùng chung, đồng thời cập nhật entry points để trỏ agent đọc file đó trước khi lập kế hoạch hoặc thực thi.

## Thay đổi chính

### Core Rules Hub

- File mới: `.agents/rules/agent-mode.md` (template: `templates/.agents/rules/agent-mode.md`).
- Nội dung: tắt Built-in Planning Mode, cấm `implementation_plan.md` / scratchpad trong `.gemini` / `.cursor` / `.claude`, chỉ cho phép kế hoạch dưới `docs/tasks/REQ-*`, yêu cầu `APPROVED_SPEC_PACKAGE` trước khi code.

### Agent Pointers

- `AGENTS.md` — `CRITICAL AGENT OVERRIDE` → đọc `.agents/rules/agent-mode.md`.
- `CLAUDE.md`, `GEMINI.md` — `**CRITICAL**` pointer trước mọi hành động.
- `.cursor/rules/ai-workflow.mdc` — pointer trong Hard gates (`alwaysApply: true`).

### Installer / build

- `sharedDirs` thêm `.agents/rules`.
- `sharedFiles` copy `agent-mode.md` vào consumer repo.
- `REQUIRED_ARTIFACTS` / `dist/bundle.json` đóng gói file hub (48 files).
- Tests regression: installer, build, governance, adapter parity.

## Phạm vi Phase 1 (không đổi workflow GA)

- **Không** tái cấu trúc canonical workflow, hard-gates phê duyệt, hoặc docs/tasks SSOT — dự kiến Phase 2–3.
- **Không** breaking change so với 3.0.0 GA về Spec Package layout hay approval tokens.

## Installation

```bash
npx 3a-factory@3.1.0-rc.1 --agent=cursor --force
npx 3a-factory@3.1.0-rc.1 --agent=gemini --force
```

Sau cài: xác nhận `.agents/rules/agent-mode.md` tồn tại; Cursor Agent chat → `/`; Gemini → `/commands reload`.

## Upgrade từ 3.0.0

```bash
npx 3a-factory@3.1.0-rc.1 --agent=<your-agent> --force
```

`--force` cần thiết nếu `AGENTS.md` / `GEMINI.md` / `CLAUDE.md` / `ai-workflow.mdc` đã được tùy chỉnh cục bộ.

## Release readiness

Chạy `npm run ci` trước publish. Publish RC chỉ khi user chủ động (npm dist-tag thường là `next`).
