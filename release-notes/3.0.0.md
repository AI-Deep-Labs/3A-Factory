# Release Notes — 3.0.0

**Status:** General availability (GA). Version npm: `3.0.0`.

**Date:** 2026-07-27

## Tóm tắt

3A-Factory **3.0.0** là bản GA của dòng Feature-local Spec Package (greenfield). Mỗi feature là một package dưới `docs/tasks/REQ-<NNNNNN>-<slug>/`, với ownership artifact rõ, develop theo task, QA theo acceptance, converge trước user review, và deploy approval tách biệt.

Candidate path: [rc.1](./3.0.0-rc.1.md) → [rc.2](./3.0.0-rc.2.md) → [rc.3](./3.0.0-rc.3.md) → [rc.4](./3.0.0-rc.4.md) → [rc.5](./3.0.0-rc.5.md) → [rc.6](./3.0.0-rc.6.md).

## Điểm chính

- **Spec Package** dưới `docs/tasks/` (không dùng `.specs/`).
- Artifact truth: `requirements.md` / `design.md` / `tasks.md` / `acceptance.md` / `manifest.yaml`.
- Approvals: `APPROVED_SPEC_PACKAGE`, `APPROVED_DEVELOP`, `APPROVED_USER_REVIEW`, `APPROVED_DEPLOY`.
- Installer: Claude / Gemini / Cursor; npm lifecycle không scaffold nhầm agent.
- Cấp số REQ/ADR: agent quét basename thật dưới `docs/tasks/` → `next = max + 1` (không có → `000001`).

## Breaking changes

Xem [BREAKING-CHANGES.md](../BREAKING-CHANGES.md). Không có migration path từ 2.x.

## Installation

```bash
npx 3a-factory@3.0.0 --agent=cursor
# hoặc claude / gemini / all
npx 3a-factory@3.0.0 --agent=gemini --force
```

Sau cài: Cursor Agent chat → `/`; Gemini → `/commands reload`.
