# Release Notes — 3.0.0-rc.1

**Status:** Superseded by [3.0.0-rc.5](./3.0.0-rc.5.md) (via rc.2–rc.4). Kept for history.

## Tóm tắt

3A-Factory **3.0.0-rc.1** là bản candidate của dòng 3.0.0: chuyển toàn bộ vòng đời feature sang **Feature-local Spec Package** — mỗi request là một package dưới `docs/tasks/`, có manifest, ownership artifact rõ, develop theo task, QA theo acceptance, converge trước user review, deploy approval tách biệt.

## Vì sao thay đổi

Single-document spec và artifact phân tán khó gate approval, khó trace task/QA, và dễ drift giữa agent. Greenfield loại bỏ legacy để contract sạch.

## Spec Package là gì

Một thư mục `docs/tasks/REQ-<NNNNNN>-<slug>/` gồm `manifest.yaml` + raw/discovery/analysis + requirements/design/tasks/acceptance/spec-review + `decisions/` / `reviews/` / `qa/` / `release/`.

## Lợi ích

- Ownership không trùng lặp.
- Traceability FR/DES/TASK/AC bắt buộc.
- Approval và state machine kiểm chứng được bằng validator + CI.
- Multi-agent (Claude, Gemini, Cursor) cùng semantic.

## Supported agents

Claude Code, Gemini CLI, Cursor.

## Workflow mới

Xem [docs/workflow.md](../docs/workflow.md). Không có `/plan`.

## Approval model

`APPROVED_SPEC_PACKAGE` → (optional `APPROVED_DEVELOP`) → … → `APPROVED_USER_REVIEW` → `done` → deploy chỉ với `APPROVED_DEPLOY`.

## Breaking changes

Xem [BREAKING-CHANGES.md](../BREAKING-CHANGES.md) (áp dụng cho cả dòng 3.0.0 / rc).


Installer không tạo `docs/tasks/`.

## Validation status

- Đây là **pre-release**: API/docs có thể chỉnh trước GA `3.0.0`.
