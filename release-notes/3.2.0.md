# Release Notes — 3.2.0

**Status:** General availability (GA).  
**Date:** 2026-07-29  
**Base:** [3.1.0-rc.4](./3.1.0-rc.4.md) → [3.0.0](./3.0.0.md) GA.

## Tóm tắt

3A-Factory **3.2.0** là bản GA gom toàn bộ cải tiến từ dòng 3.1.0-rc: **auto-intake**, **approval tự nhiên**, **PM mode bắt buộc**, **authoring phẳng dưới `.agents/`**, **slash command full body**, và **onboarding theo agent**.

---

## Điểm chính

### Workflow UX

| Tính năng | Mô tả |
|---|---|
| **Auto-intake** | Repo đã onboard → mô tả yêu cầu bằng ngôn ngữ tự nhiên; agent tự route qua `project-manager` theo `manifest.status` |
| **Approval tự nhiên** | Mỗi gate hỏi xác nhận yes/no, có/không — không bắt buộc gõ token `APPROVED_*` |
| **PM mode bắt buộc** | `/project-manager` ép chạy đúng workflow, không skip phase |
| **Core Rules Hub** | `.agents/rules/agent-mode.md` — chống planning mode ngầm, cấm artifact ẩn |

### Authoring layout

```
.agents/
├── WORKFLOW.md
├── commands/     ← source of truth (full body)
├── skills/       ← workflow skill bodies
├── contracts/
├── rules/
├── schemas/
└── templates/
```

- Không còn wrapper `templates/`.
- Slash command (Claude `.md`, Gemini `.toml`, Cursor `.mdc`) nhúng **full body** từ `.agents/commands/` — có thể custom độc lập với skill.

### Onboarding

Chỉ tạo context file cho agent đang chạy:

| Agent | Files |
|---|---|
| Claude | `AGENTS.md` + `CLAUDE.md` |
| Gemini | `AGENTS.md` + `GEMINI.md` |
| Cursor | `AGENTS.md` + `.cursor/rules/` |

---

## Breaking changes (authoring only)

Không breaking cho consumer runtime. Nếu bạn fork/custom **nguồn authoring**:

- Path cũ `templates/skills/`, `templates/commands/` → `.agents/skills/`, `.agents/commands/`
- Slash command không còn pointer-only; body nằm trực tiếp trong file command

Xem [BREAKING-CHANGES.md](../BREAKING-CHANGES.md) § 3.2.0.

## Installation

```bash
npx 3a-factory@3.2.0 --agent=<your-agent>
```

Ví dụ:

```bash
npx 3a-factory@3.2.0 --agent=cursor --force
npx 3a-factory@3.2.0 --agent=claude --force
npx 3a-factory@3.2.0 --agent=gemini --force
npx 3a-factory@3.2.0 --agent=all --force
```

### Upgrade từ 3.0.0 hoặc 3.1.0-rc.x

```bash
npx 3a-factory@3.2.0 --agent=<your-agent> --force
```

Sau reinstall, bắt đầu chat mới nếu danh sách `/` bị stale.
