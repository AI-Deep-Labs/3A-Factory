# Release Notes — 3.2.2

**Status:** Patch release (GA line).  
**Date:** 2026-08-03  
**Base:** [3.2.1](./3.2.1.md)

## Tóm tắt

3A-Factory **3.2.2** nâng cấp toàn diện skill **Specification Synthesizer** (trước đây là `synthesize-design-doc`). Kiến trúc mới áp dụng thiết kế declarative để phân tách minh bạch giữa việc tổng hợp từ hội thoại (Mode 1) và củng cố spec đã có sẵn (Mode 2), qua đó triệt tiêu rủi ro AI tự ý ghi đè lên các artifact gốc đã được chốt (như `requirements.md`, `design.md`). 

---

## Vì sao có bản này

Tên skill cũ (`synthesize-design-doc`) chỉ giới hạn chức năng sinh tài liệu đơn thuần. Ở môi trường AI Agent dài hạn, Agent cần khả năng phân biệt rõ input (conversation context vs spec files) để không làm mất traceability và không gây hallucination. Kiến trúc declarative giúp mô hình tự nhận thức các giới hạn nghiêm ngặt này.

---

## Điểm chính

### 1. Specification Synthesizer (Upgraded)

- **Đổi tên:** Thay thế `synthesize-design-doc` bằng `specification-synthesizer` trên toàn hệ thống (commands, build scripts, docs, intent gate).
- **Mode 1 (Conversation Synthesis):** Tự động phát hiện khi input đến từ hội thoại, tổng hợp thành bộ Spec Package thô (requirements, design, tasks, ...).
- **Mode 2 (Specification Consolidation):** Khi có REQ-NNNNNN, Agent đọc bộ Spec gốc làm **Source of Truth** và sinh các tài liệu tổng quát (BRD, TDD, Handoff) vào thư mục con `/synthesis/` hoặc `docs/misc/compact/`. Không bao giờ overwrite file cốt lõi.
- **Traceability & Anti-Hallucination:** Ngăn cản AI bịa API, business logic. Yêu cầu tạo section `## Open Questions` nếu context không đủ. Bắt buộc map `Requirement → Design → Acceptance → Task`.

### 2. Đồng bộ các đường dẫn

Cập nhật lại references trên toàn bộ config và build script (như `scripts/build.js`, `CLAUDE.md`, `GEMINI.md`, v.v.) sang tên lệnh mới `/specification-synthesizer`.

---

## Không đổi (không breaking)

- Canonical workflow / Spec Package contract semantics
- Approval gates
- Consumer paths (`.agents/skills`, `.claude/commands`, `.gemini/commands`, `.cursor/rules`)
- Luồng Routing `project-manager`

## Installation / Upgrade

```bash
npx 3a-factory@3.2.2 --agent=<your-agent> --force
```

Ví dụ:

```bash
npx 3a-factory@3.2.2 --agent=cursor --force
npx 3a-factory@3.2.2 --agent=claude --force
npx 3a-factory@3.2.2 --agent=gemini --force
npx 3a-factory@3.2.2 --agent=all --force
```

Sau upgrade: mở chat Agent mới nếu danh sách `/` hoặc always-rules còn cache bản cũ.
