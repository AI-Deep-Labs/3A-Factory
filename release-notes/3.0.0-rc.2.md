# Release Notes — 3.0.0-rc.2

**Status:** Superseded by [3.0.0-rc.6](./3.0.0-rc.6.md) (via rc.3–rc.5). Kept for history.

## Tóm tắt

3A-Factory **3.0.0-rc.2** tiếp tục dòng candidate 3.0.0 (Feature-local Spec Package), với chỉnh sửa installer/CI so với [3.0.0-rc.1](./3.0.0-rc.1.md).

## Thay đổi chính so với rc.1

- Installer **không** ghi `.3a-factory/install-manifest.json`.
- Installer chỉ scaffold `docs/`; **không** pre-create `docs/decisions` / `docs/misc` (skills tạo khi ghi file).
- `npm test` ổn định trên Linux CI (explicit test files + concurrency 1).
- **Slash skills (Cursor/Gemini):** slim layout — skill body only in `.agents/skills/`; Cursor `.cursor/rules/<skill>.mdc`; Gemini `.gemini/commands/*.toml` → `.agents/skills/` (no `.cursor/skills` / `.gemini/skills` mirrors).

## Spec Package / workflow

Không đổi contract lõi so với rc.1. Xem [docs/workflow.md](../docs/workflow.md), [BREAKING-CHANGES.md](../BREAKING-CHANGES.md).

## Installation

```bash
npx 3a-factory@3.0.0-rc.2 --agent=cursor
```

Installer không tạo `docs/tasks/`, không tạo `.3a-factory/`, không pre-create `docs/decisions` / `docs/misc`.

Theo `RELEASE-CHECKLIST.md` và `docs/reports/`. Publish RC chỉ khi user chủ động.
