# Release Notes — 3.1.0-rc.4

**Status:** Pre-release candidate.  
**Base:** [3.1.0-rc.3](./3.1.0-rc.3.md).

## Tóm tắt

3A-Factory **3.1.0-rc.4** bỏ wrapper `templates/`, gom toàn bộ nguồn authoring vào `.agents/`, và nhúng **full body** vào slash command (Claude / Gemini / Cursor) để file command là source of truth — có thể custom độc lập với skill.

---

## Thay đổi chính

### 1. Flatten: xóa `templates/`, mọi thứ dưới `.agents/`

| Trước (rc.3) | Sau (rc.4) |
|---|---|
| `templates/skills/<name>/SKILL.md` | `.agents/skills/<name>/SKILL.md` |
| `templates/commands/<name>.md` | `.agents/commands/<name>.md` |
| `templates/WORKFLOW.md` | `.agents/WORKFLOW.md` |
| `templates/.agents/{contracts,rules,schemas,templates}/` | `.agents/{contracts,rules,schemas,templates}/` |

Installer, build (`dist/bundle.json`), validation và tests đọc path `.agents/…`. Không còn thư mục `templates/` trong repo nguồn.

### 2. Slash command = full body (source of truth)

- Mỗi `.agents/commands/<name>.md` chứa **toàn bộ** nội dung skill (sau frontmatter), không còn prompt kiểu “Read AGENTS.md rồi execute SKILL.md”.
- Installer chỉ **đọc file command → emit** format agent:
  - Claude → `.claude/commands/<name>.md`
  - Gemini → `.gemini/commands/<name>.toml`
  - Cursor → `.cursor/rules/<name>.mdc`
- Có thể tắt/custom slash mà vẫn giữ skill trong workflow, hoặc dùng slash độc lập khi skill không nằm trong pipeline.

### 3. Scripts / docs

- `scripts/install.js`, `scripts/build.js`, `scripts/validation/*`, tests cập nhật path.
- `AGENTS.md`, `README.md`, `docs/commands.md`, `docs/workflow.md`, `docs/approvals.md`, CHANGELOG, release notes đồng bộ **3.1.0-rc.4**.

---

## Installation

```bash
npx 3a-factory@3.1.0-rc.4 --agent=<your-agent> --force
```

Ví dụ:

```bash
npx 3a-factory@3.1.0-rc.4 --agent=cursor --force
npx 3a-factory@3.1.0-rc.4 --agent=claude --force
npx 3a-factory@3.1.0-rc.4 --agent=gemini --force
```
